# Ting-Media

面向自媒体创作者的 **短视频 / 图文高效工作流** 开源沉淀。

把「选题 → 脚本 → 拍摄/生成 → 剪辑字幕 → 封面 → 发布复盘」拆成可复用的模板、清单和工具用法，降低日更成本，提高可持续产出。

> 仓库地址：[https://github.com/Ting-Code/Ting-Media](https://github.com/Ting-Code/Ting-Media)

---

## 背景

自媒体难的不是「会不会剪」，而是：

- 选题不稳，更新断档
- 工具太多，流程不固定
- 口播 / 图文 / 封面每次从零开始
- 追热点有流量，却难形成长期资产

Ting-Media 希望把经过验证的流程沉淀成 **可复制的资产**，而不是零散经验。

---

## 目标

1. **流程标准化**：一套能日更的短视频 / 图文流水线
2. **模板资产化**：脚本、字幕、封面、发布检查表可直接套用
3. **工具组合清晰**：剪映 + AI 文案 + 封面工具，各司其职
4. **可持续赛道导向**：优先沉淀可系列化、可复用的内容方法

---

## 适用人群

- 个人创作者（口播 / PPT 分析 / 图文卡片）
- 想建立「一人公司」式内容产能的人
- 需要把 AI 真正嵌进剪辑与发布流程的团队或工作室

## 已接入工具

### `tools/stock-analysis` — A 股单票复盘页

输入股票名称或代码，生成 **9:16 竖屏** 可交互 HTML（行情 K 线 / 季报 / 估值序列），适合录屏做财经复盘短视频。

```bash
cd tools/stock-analysis
pip install -r requirements.txt
python scripts/generate_stock_html.py 宁德时代
```

说明见 [`tools/stock-analysis/README.md`](tools/stock-analysis/README.md) 与 [`tools/stock-analysis/AGENTS.md`](tools/stock-analysis/AGENTS.md)。

该子模块为个人学习与复盘用途，**不授权商用**。

## 核心工作流（简版）

### 短视频（推荐 20–40 秒快节奏口播）

1. AI 出选题与口播稿（钩子 → 三点干货 → CTA）
2. 拍摄或 AI 配音
3. 剪映：粗剪 → 智能字幕 → 关键词花字 → 导出
4. 封面：剪映选帧加大字，或 Canva/稿定套模板
5. 发布后记录完播、互动，周复盘

### 图文

1. 先写「可口播」的结构化文稿
2. 拆成小红书卡片 / 公众号正文
3. 固定封面模板，只改文案

### 工具分工

| 环节 | 建议工具 |
|------|----------|
| 选题 / 脚本 / 封面文案 | GPT / Kimi / 豆包 等 |
| 剪辑 / 字幕 / 基础封面 | 剪映 |
| 精致封面 / 统一视觉 | Canva / 稿定设计 |
| 封面底图（可选） | GPT 生图 / 即梦 等（大字仍建议后期叠加） |

## 内容原则

- **完播优先于时长**：大众向内容优先 1 分钟以内，常见高流量区间约 15–45 秒
- **模板化 > 每次灵感创作**：字幕样式、封面版式、脚本结构尽量固定
- **赛道可持续**：技能教学、垂直干货、可系列化主题优先于纯热点
- **形式可组合**：口播、录屏、PPT/卡片、实操演示按内容选择，不唯出口播
