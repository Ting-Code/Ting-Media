# Ting-Stock-Analysis 产品方案（已确认方向）

> 记录时间：2026-10-22  
> 定位：自媒体财经复盘内容生产（科普/复盘口径，不荐股、不承诺收益）

## 1. 大方案

**浏览器内容工作台**：以网页为展示与交互壳，背后分离数据、AI 解读、文案输出。

主链路：

1. 输入股票代码 + 时间区间  
2. 页内展示可交互 K 线（及饼图等图表）  
3. AI 按模板产出文字解读  
4. 人工微调后，复制为短视频口播 / 图文要点  

原则：

- **不是全部用 HTML**：HTML 只做门面（展示、交互、跨端打开）  
- 数据获取/存储、AI 解读、口播稿等能力独立，不塞进静态大页里硬写  
- 飞书/语雀可作为发稿备份，不当分析主界面（AI 读上下文不便）

## 2. 高效出页方式（母版 + 填空）

- 先定 **HTML 母版**（版式固定：标题、摘要、K 线、饼图、分段解读、口播要点、免责声明）  
- 每次只准备 **分析数据包**（行情数据 + 图表数据 + 文案）  
- 用 **积木块** 拼装（K 线块 / 饼图块 / 文本块），避免每篇让 AI 重写整页 HTML  
- AI 负责文案与数据组织；固定渲染负责生成最终页面

## 3. 合规边界

- 可做：K 线科普、历史复盘、方法论、情景推演  
- 不做：明确买卖点推荐、收费跟投、承诺收益  
- 页面固定免责声明：仅供参考，不构成投资建议

## 4. 与当前代码的关系

仓库里现有 `app.py` + `src/*` 是早期 **Streamlit 可交互 K 线试做**，用于验证「取数 + 交互图」。  
最终方向是 **HTML 展示壳 + 后端能力分离**；试做代码可保留作参考，或后续收敛进正式架构。

## 6. 单票分析流水线（你发股票/板块 → 出 HTML）

输入：股票代码或板块；可选年限。  
输出：一份 HTML 复盘页（图表可交互 + 文案位）。

### 模块 A：行情 K 线

1. 拉取上市以来（或指定年限）**日线** OHLCV（建议前复权）  
2. 按需要重采样为：**日 / 周 / 月 / 季**（季线可用财季或自然季，需固定一种）  
3. 页内可切换周期与年限，画可交互 K 线 + 成交量（可选均线）

### 模块 B：季度财报趋势

1. 拉取上市以来季报关键科目，至少：  
   - 营业总收入  
   - 归母净利润  
   - **扣非净利润**  
   -（可选）经营现金流、毛利率、ROE  
2. **图表形态用柱状/折线按季展示**，不是蜡烛 K 线（K 线留给股价）  
3. 页内可切换展示粒度：单季 / 同比 / 累计；若做「年线」则用年报或四季合计

### 模块 C：估值序列（季度点）+ 对比现价

对每个已披露季度，构造一个「估值观察点」：

1. **锚定日**：该季报**实际发布日**的「次月」代表价（建议默认：次月最后一个交易日收盘价；备选：次月均价）  
   - 用意：避开公告前后剧烈博弈日，用信息消化后的价格  
2. **盈利口径（动态 PE）**：优先用 **TTM 扣非** = 该季及之前连续 4 个完整报告期扣非之和  
   - `动态PE ≈ 锚定日收盘价 / 每股TTM扣非`  
   - 或 `总市值(锚定日) / TTM扣非总额`（与上式等价，注意股本口径一致）  
   - **不要**只用单季扣非×4 当主口径（季节性行业会严重失真）；可作辅助对照  
3. 同一锚定日标注：  
   - **市净率 PB** = 价 / 最近报告期每股净资产（或市值/归母净资产）  
   - **股息率** = 近12个月现金分红每股股利 / 价（或总分红/市值）  
4. 页上画「季度估值点」折线/散点，并标出**当前股价**对应的：  
   - 当前 PE（用最新可得 TTM 扣非）  
   - 当前 PB、当前股息率  
   - 与历史分位对比（如当前 PE 处于历史序列的百分之多少）

### 分析文案建议顺序（给 AI 填模板）

1. 价格位置：现价相对所选年限的高低、趋势结构（模块 A）  
2. 盈利质量：营收/扣非趋势、是否走扩、是否季节性（模块 B）  
3. 估值位置：当前 PE/PB/股息率 vs 历史季度点分位（模块 C）  
4. 三者合读：赚得多不多、贵不贵、价格是否已反映（只做复盘，不给买卖点）

### 已确认口径

| 项 | 口径 |
|----|------|
| 复权 | 前复权 |
| 季线聚合 | 自然季末最后一个交易日 |
| 锚定价 | 季报发布日「次月」**月末最后一个交易日收盘价**（不用月均价） |
| PE | TTM 扣非 |
| 股息率 | 近 12 个月已实施现金分红 / 现价 |
| 范围 | **第一版只做单票**；板块（指数/成分股聚合）放第二版 |

## 8. AI / 协作者如何复现出页

克隆仓库后，以根目录 `AGENTS.md` 与 `.cursor/rules/` 为 AI 上下文入口。  
标准做法：安装依赖后执行 `python scripts/generate_stock_html.py <股票>`，或让 AI 按该命令跑流水线，禁止从零手写无数据 HTML。

详见 [`docs/AI协作指南.md`](AI协作指南.md) 与根目录 `AGENTS.md`。

## 9. 展示形态（已确认）

默认按 **9:16 竖屏** 优化（手机宽约 420px 居中栏、指标 2×2、分块可截短视频分镜）。  
宽屏不拉成横版仪表盘，两侧留白，保持同一竖栏阅读/截图体验。

## 10. 录屏形态（已确认）

- 默认 **9:16 PPT 分镜**：一屏一页，下一页平滑滚到整页
- **安全区**：顶约 12% / 底约 18%（抖音、B 站点赞评论等）；图表与核心数字只放中间安全带
- 操作：空格/↓/→ 下一页；↑/← 上一页；`G` 切换安全区示意
- 规范：`shared/workflow/9-16-录屏规范.md`
