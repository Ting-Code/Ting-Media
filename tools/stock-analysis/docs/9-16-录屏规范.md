# 录屏页视觉规范（已定稿 · 可复用）

**权威实现**：`src/_deck_template.html` + `src/_deck_nav.js` + `src/render_report.py`  
出新一期时**只换数据/文案**，不得另起炉灶改布局或主题。入口：`scripts/generate_stock_html.py`。

## 工作台布局（固定）

```
[ 9:16 录屏框 ]  [ 口播文案（同高、内部滚动） ]  [ 翻页 页码↑↓ ]
```

- 水平居中；整页 `100dvh` + `overflow:hidden`（**无页面级滚动条**）。
- 录屏框：固定比例 **9:16**；高度 `min(853px, 100dvh - 48px)`，宽度由高度算出。
- 文案区：定宽约 `560px`，**高度与录屏框对齐**，列表内部滚动；卡片高度随文案自适应（勿 flex 压扁）。
- 翻页：文案右侧；页码单行 `n/N` 在按钮上方；无圆点指示器。
- 录屏框内滚动条 **隐藏**（仍可滚轮/快捷键翻页）。

## 主题（One Dark · 固定）

| 用途 | 色 |
|------|-----|
| 工作台底 | `#1e2227` |
| 面板 | `#282c34` / `#2c313c` |
| 线 | `#3e4451` |
| 正文 | `#abb2bf` |
| 强调 | `#61afef`（蓝）`#56b6c2`（青）`#c678dd`（紫） |

录屏框内同样深色；图表用 `plotly_dark`，无 modebar；图标题不重复（页上已有 h2）。

## 安全区与边距

原则：**护核心，不硬留大块空白；左右对称小边。**

| 变量 | 值 | 说明 |
|------|-----|------|
| `--safe-top` | 14% | 顶栏 |
| `--safe-bottom` | 32% | 底栏文案/搜索/导航 |
| `--safe-left` / `--safe-right` | 1.2% | 左右对称小边 |

- 图表页：标题区尽量薄；说明行可隐藏；**图铺满中间可用区**；Plotly margin 尽量小（约 4–6px）。
- `G` /「安全区」：示意遮挡带，≠强制四周留白。

## 分镜结构（内容可变，骨架不变）

1. 封面要点（指标卡片）
2. A 行情 K 线（可切日周月季）
3. B 季度财务
4. C 指标序列
5. 收尾说明

每页 `data-title` / `data-script` 为左侧口播；换期只改这些与数据槽位。

## 禁止

- 手写整页 HTML / 换浅色仪表盘 / 破坏三栏工作台
- 为「安全」把图表挤成细条或单侧贴边
- 生成后把母版 CSS 改成另一套主题（改规范需先改本文件与母版，再出页）
