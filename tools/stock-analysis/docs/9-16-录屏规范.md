# 9:16 录屏规范（本工具 HTML）

> 公共目录约定见仓库 `docs/目录规划.md`。

面向竖屏短视频录屏：页面按 **PPT 分镜** 一屏一页，点击或快捷键切页，重点内容避开平台 UI 遮挡区。

## 画幅

- 比例：**9:16**
- 工作台 HTML 舞台宽约 **420px** 居中；录屏时只框舞台，或全屏后裁成 9:16
- 一页 = 一屏（`100dvh`），不要在一页里上下长滚讲完

## 安全区（必须避开）

平台点赞、评论、头像、标题、进度条会挡住上下区域。生成页用 CSS 变量预留：

| 区域 | 建议预留 | 说明 |
|------|----------|------|
| 顶部安全区 | 约 **12%** 屏高（≥ 88px） | 状态栏、标题、关注按钮 |
| 底部安全区 | 约 **18%** 屏高（≥ 140px） | 点赞 / 评论 / 分享 / 音乐条 |
| 左右 | 约 **4%** 宽 | 边缘手势与头像列（抖音偏右） |

**重点标题、数字、图表主体只放在中间「内容安全带」内。**  
页脚提示、免责声明可放底栏附近，但不要当口播主信息。

录前可在页面打开「安全区示意」开关（半透明红带），确认无遮挡后再关。

## PPT 式交互（录屏丝滑）

复盘 HTML 采用分镜：

1. 封面（名称 + 四指标）
2. A 行情 K 线
3. B 季度财报
4. C 估值序列
5. 免责声明（可口述带过，不一定出镜）

操作：

- **下一页**：按钮 / `→` / `空格` / `PageDown`
- **上一页**：按钮 / `←` / `PageUp`
- 切换为 **smooth** 滚到整页，禁止录制时用手势乱滑导致画面抖动

口播节奏建议：每页 8–20 秒，切页卡在句子停顿处。

## 录制检查清单

- [ ] 舞台为竖屏，未录到桌面两侧杂物（或已裁切）
- [ ] 安全区示意确认后已关闭
- [ ] 图表字号在手机预览下可读
- [ ] 切页只用键鼠固定方式，全程一致
- [ ] 口播无买卖建议、无承诺收益
