# 方案（tools/stock-analysis）

取数口径见 `tools/stock-data/docs/数据源规范.md`。

## 定位

浏览器内容工作台：HTML 只做展示壳；数据与文案分离。默认 9:16 竖屏。生成数据仅供参考，不构成决策依据。

## 主链路

输入名称或代码 → 跑流水线 → 生成 HTML。第一版单标的。

## 三块内容

- **A** 行情 K 线（日/周/月/季）
- **B** 季度财务趋势
- **C** 指标序列：季报发布日次月月末收盘为锚；TTM 扣非市盈、市净、股息率，对比现价分位

## 出页

母版 + 数据包填空；入口 `scripts/generate_stock_html.py`。禁止从零手写无数据 HTML。
