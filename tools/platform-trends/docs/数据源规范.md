# 跨平台热度数据源（一期 · 免 Key）

目标：平台上什么作品 / 话题在火。不登录、不存 Cookie、不绕过风控。

| 平台 | 接口 | 条目类型 | 赛道字段 |
| --- | --- | --- | --- |
| B站 | `https://api.bilibili.com/x/web-interface/popular`、`.../ranking/v2` | 作品 | 分区 `tname` |
| 微博 | `https://weibo.com/ajax/side/hotSearch`；辅 `.../ajax/statuses/hot_band` | 话题 | `category`（有则用） |
| 抖音 | `https://www.iesdouyin.com/web/api/v2/hotsearch/billboard/word/` | 热词 | 无 → `未标注` |

小红书、视频号：**未接入**（无稳定免 Key 公开源）。

## 统一字段

- `kind`: `work` | `topic`
- `platform`: `bilibili` | `weibo` | `douyin`
- `title`, `rank`, `heat`（平台原值，**不跨平台换算成同一分数**）
- `niche`, `url`, `author`（有则填）

## 分析口径

1. 各平台 Top 保留原榜顺序
2. B站按分区聚合作品数、播放、点赞
3. 微博有 category 的条目做分类分布
4. 跨平台对照：标题规范化后做子串 / 字符重叠，标多平台同时出现；热度数值不跨平台相加

## 稳健

合理 UA / Referer、限速、重试。单平台失败不拖垮整次运行，报告里标明。

公开接口非正式授权 API，可能风控或变更。生成数据仅供参考，不构成决策依据。

## 默认产出

控制台数据摘要（可加 `--json` 写 `output/`）。**只有明确要录屏节目时才用 `--html` 出 9:16 页。**
