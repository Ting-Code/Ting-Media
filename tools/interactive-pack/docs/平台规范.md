# 互动 HTML 平台规范（工具内置）

机器可读副本：`src/platform_specs.json`（`python scripts/cli.py specs`）。

> 平台规则会变；以上传页 / 官方文档为准。本文件是仓库内可执行约束的摘录。

## 共同底线（`common`）

- 入口：`index.html`
- **禁止**外网：无 `http(s)` CDN、无 `fetch` / XHR / WebSocket
- **禁止** `eval` / `new Function` / WASM / `iframe`
- **脚本外置** `.js`（兼容小红书；也通抖音/B站）
- zip 总量按 **8MB**（抖音）控；入口 HTML 按 **1MB**（B站）控

## 抖音互动空间

- 上传：https://vcreate.douyin.com/
- zip ≤ **8MB**；可粘贴单文件或上传多文件 zip
- 允许内联 script；允许多文件
- 纯离线；常见内测配额约 100 作品 / 约 100 人同时在线（以页面为准）

## B站 Toy

- 介绍：https://www.bilibili.com/toy/intro
- **入口 `index.html` 解压后 ≤ 1MB（硬限制）**
- 相对路径；避免根绝对路径 `/xxx`（页挂在 `/toy/<slug>/`）
- 可用官方 toy CLI

## 小红书小工具

- 脚本必须外置；**禁止内联 `<script>` 与 `onclick=`**
- 禁止 eval / WASM / iframe
- zip 常见上限约 **5–10MB**
- 兼容基线约 Chrome 61 / Android 8.1
- 开发口令以上传页当前说明为准

## 与录屏 HTML 的区别

- `screen-pack` / `platform-trends --html`：9:16 **录屏母版**，给剪辑用，不保证能过互动审核。
- 本工具：给 **互动空间 / Toy / 小工具** 上传的离线包。
