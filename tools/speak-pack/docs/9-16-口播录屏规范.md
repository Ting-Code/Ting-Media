# 口播录屏页视觉规范（已定稿 · 可复用）

**权威实现**：`src/_speak_template.html` + `src/_speak_nav.js`  
出新一期时**只换口播稿 / 句子 / 生词**，不得另起炉灶改布局或主题。入口：`scripts/generate_speak_html.py`。

本工具与 `tools/screen-pack` 相互独立。工作台尺寸、主题色和安全区与股票录屏页对齐，但**录屏框内部是口播版式**，不要把股票图表母版改成这一套，也不要把本母版改回图表页。

## 工作台布局（固定）

```
[ 9:16 录屏框 ]  [ 口播文案（同高、内部滚动） ]  [ 翻页 页码↑↓ ]
```

- 水平居中；整页 `100dvh` + `overflow:hidden`（**无页面级滚动条**）。
- 录屏框：固定比例 **9:16**；高度 `min(853px, 100dvh - 48px)`，宽度由高度算出。
- 文案区：定宽约 `560px`，**高度与录屏框对齐**，列表内部滚动；卡片高度随文案自适应。
- 翻页：文案右侧；页码单行 `n/N` 在按钮上方；无圆点指示器。
- 可选左右对调：翻页栏「左右」或快捷键 `L`（口播↔录屏）；默认仍为左录屏。偏好存 `localStorage`。

## 安全区与边距

与股票录屏页相同：

| 变量 | 值 | 说明 |
|------|-----|------|
| `--safe-top` | 14% | 平台状态栏预留；录屏框内不放分页、日期或标题说明 |
| `--safe-bottom` | 32% | 平台底栏预留；字幕不得伸进此带 |
| `--safe-left` / `--safe-right` | 1.2% | 左右对称小边 |

`G` /「安全区」：示意遮挡带，≠强制四周留白。

## 录屏框内部（口播版式，固定）

```
[ 顶 14% / 底 32% / 左右 1.2%：遮挡预留，不放文字 ]
[ 安全区内靠上、左对齐：英文原句（生词高亮） / 中文意思 / 生词重点 ]
[ 其余区域留空，给人像或成片在后期叠上去 ]
```

- 安全区算法与 `screen-pack` 相同：内容避开顶部 14%、底部 32%、左右 1.2%。`G` /「安全区」只是把这四条遮挡带画出来。
- **字幕**放在安全区顶部、左对齐：第一行英文原句，生词用橙色高亮；第二行中文意思；第三行生词重点（词 + 释义）。不得进入顶栏或底栏遮挡带。翻页只换字幕和口播词。
- **其余区域**保持空白（深色底），给人像或成片在后期叠上去。本页不内置录屏、摄像头或本地视频选择。
- 录屏框内**不显示**分页、日期或标题说明；页码只出现在工作台右侧翻页栏。
- 一页一句（或一句口播单元）。封面、收尾也用同一骨架，只换文案。

## 分镜结构（内容可变，骨架不变）

1. 开场点题
2. 跟读句（可多页，一页一句）
3. 收尾

每页的 `title` / `script` 为右侧口播；`en` / `zh` / `words` 为录屏框安全区内的字幕。换期只改 JSON。

## 禁止

- 手写整页 HTML / 换浅色主题 / 破坏三栏工作台
- 改 `tools/screen-pack` 的股票录屏母版或 `9-16-录屏规范.md` 来迁就口播页
- 生成后把本母版 CSS 改成另一套主题（改规范需先改本文件与母版，再出页）
