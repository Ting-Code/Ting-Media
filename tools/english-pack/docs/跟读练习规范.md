# 跟读练习规范

`english-pack` 生成的是**自用横版练习页**，不是 9:16 录屏页，也不写入 `episodes/`。

## 交互

- 一次只展示一句英文。
- 默认用浏览器 `speechSynthesis` 播放英语原句；可选择英语语音、调节语速（0.70×–1.15×）、循环跟读。
- 英文原句中标出词汇，并在下方给出中文意思；可附一句使用场景。
- 可隐藏字幕（英文、中文和词表一起藏）以便回忆，再显示对照。
- 「会了」将当前句记为已掌握，并跳到下一句未掌握的句子；「再练」取消已掌握并重新播放。
- 进度按课程 id 写入本机 `localStorage`，不上传。
- 不录音、不做语音识别、不评分。
- 不调用付费或外部语音 API。
- 可选：句子提供本地音频相对路径时，优先播放该音频，失败再回退到语音合成。

## 语音与兼容

页面必须写明：

- 使用浏览器 / 系统自带语音合成；
- 能否听到英语取决于是否已安装英语语音包；
- 未检测到英语语音，或浏览器不支持 `speechSynthesis` 时，应给出说明并优雅降级（禁用播放和循环，或提示将使用默认语音）。

## 课程 JSON

根对象字段：

- `id`：课程标识，小写字母、数字和连字符
- `title`：课程名
- `subtitle`、`description`：可选说明
- `sentences`：非空数组

每句字段：

- `id`：句标识，课程内唯一
- `en`：英文原句
- `zh`：自然、准确的中文释义
- `note`：可选，使用场景
- `words`：词条列表，`text` 必须能在 `en` 中按原文找到（不区分大小写），`meaning` 为该语境下的中文意思
- `audio`：可选，相对课程 JSON 所在目录的本地音频路径，禁止 `..` 和绝对路径

换课只换 JSON，再运行 `scripts/generate_practice.py`。练习页的 HTML/CSS/JS 模板可以在 `src/` 里直接维护。

## 输出位置

生成结果写到 `tools/english-pack/practice/<课程id>/`，是自包含的 `index.html`（样式和脚本内联）。不要写到 `episodes/`，也不要改 `speak-pack` 或 `screen-pack`。
