# 分析口径（tools/stock-screener）

基本面面板与 PE/PB 序列在本工具；原始财报/行情由 `tools/stock-data` 提供。

## 模块

| 能力 | 模块 |
|------|------|
| 基本面面板 + PE/PB | `src/analysis.py` |
| 技术面选股流水线 | `src/pipeline.py` + `filters/` |

## 单股 / 板块 PE / PB 口径（通用）

适用范围：**单股**与**板块/指数成分聚合**同一套时点规则（上一季财务 + 本季末价；未季末用最新价）。

对每个**观察季度 T**（自然季末；若当季未结束，则观察日=今日）：

| 项 | 规则 |
|----|------|
| 股价 | **本季末**最后交易日收盘；当季未结束 → **最新当日**收盘 |
| 盈利 | **上一季度**季报的**单季扣非净利润**（累计先拆单季） |
| 营收 | 上一季度单季营收（辅助序列，不进 PE） |
| 净资产 | 上一季度季报归母净资产（算 PB） |
| PE | 股价 ÷（上一季单季扣非 / 股本 × **4**）→ 年化；口播须说明 |
| PB | 股价 ÷（上一季归母净资产 / 股本） |

- 用「已披露的上一季扣非」配「本季末（或最新）价」。
- 单季扣非 ≤ 0 或缺失 → 该点 PE 留空。
- 旧口径「NOTICE 次月月末 + TTM 扣非」已废弃。


### 板块

- 时点与单股相同：观察季度 T 用**本季末价**（或最新价），盈利/净资产用**上一季度**已披露数据。
- 板块 PE/PB：先按口径算各成分（各用**自己的季末价**），再按选定权重聚合；权重与成分表须在 `meta`/口播中写明。**不是**「指数点位 ÷ 板块盈利」。
- 缺上一季扣非或净资产的成分：该点剔除并披露覆盖率，不拿其它季度偷偷填。
- 板块点位补齐规则见下方「PE 分析图」。

## PE 分析图（单股 / 板块出图时必须含）【已定稿】

同一张图、**同一套画法**（单股与板块通用）：

1. **三条序列**：季度末股价（或板块点位）、PE、PB（口径见上）
2. **纵轴**：**三条线各用独立纵轴**，各自按**当前选中区间**的历史范围拉满画布（可加约 8% 边距）；**禁止**共用同一绝对刻度，也**不要**做「末点=100」归一（归一后走势接近的序列会视觉重叠）
3. **纵轴刻度数字**：可隐藏；数值以**鼠标悬浮**为准
4. **交互**：与 ETF 分析页同一套——**主图下方色带**拖动选区、拖两端改范围；主图按选中区间重定三条纵轴。**不要** `1Y/3Y/5Y/全部` 按钮，**不要**平移 / 框选按钮，也不要滚轮缩放
5. **缺口**：某序列缺值勿连线填假（断开，不穿越空点）
6. **当前 PE**：可用虚线标出最新 PE（落在 PE 轴）

单股横版页由 `scripts/analyze_symbol.py` 写出 `cache/pe_<代码>_<行情日>/index.html`（`src/valuation_page.py`）。这不是录屏 HTML。

### 板块「点位」与 PE 的关系（勿混淆）

- **板块 PE/PB** = 各成分按上口径算出的 PE/PB，再按权重聚合。计算依赖的是**成分股价**，不是指数点位。
- **板块点位**（图画用）：
  - 有官方指数行情的区间 → 用官方指数季末收盘（未结束季用最新）
  - 官方指数尚未发布/无行情的更早区间 → 用**同期成分季末价的权重均值**，再按「与官方指数首个重叠季」对齐缩放，拼成连续点位序列（须在 `meta`/口播注明「早期为成分合成点位」）
- 因此：没有官方指数点位，仍可用成分价算 PE；点位序列应尽量补全，供与 PE/PB 同图对照。

## 调用示例

## 股息率

最近四个已结束报告期的已实施现金分红合计，除以最新不复权收盘价。

| 项 | 规则 |
|----|------|
| 分子 | 东财分红送配。这四个报告期的「现金分红-现金分红比例」除以 10，得到每股税前现金。只要方案进度为实施，且除权除息日不晚于股价日。某季没有实施分红记 0 |
| 特别分红 | 东财定期报告期表不收录特别分红，分子里没有这笔 |
| 分母 | 通达信不复权收盘价 `fetch_daily(..., adjust="bfq")` 最后一根 |
| 四个季度 | 股价日所在季度若未结束，从上一季末往前数四季。2026-11-06 对应 2025-12-31、2026-03-31、2026-06-30、2026-09-30 |

通达信 `gbbq` 的已除息现金含特别分红，用于复权。

股价用成交价（`adjust="bfq"`）。

命令行直接看一只股票：

```bash
cd tools/stock-screener
python scripts/analyze_symbol.py 603893
python scripts/div_yield.py
```

全 A 结果写到仓库根 `cache/div_yield_<行情日>/yield.csv`。

```python
import sys
from pathlib import Path
```

## 头部 ETF 持有规模占比

入口：`python scripts/etf_market_share.py`。静态网页写到仓库根 `cache/etf_market_share_<行情日>/index.html`。这不是录屏 HTML。

持有规模 = 基金份额 × 当日收盘价。占比 = 一组头部 ETF 的持有规模合计 / 对应板块总市值。不用成交额。

| 组 | 分子 | 分母 | K 线 |
|----|------|------|------|
| 沪深300 | 头部「沪深300ETF」 | 全 A 总市值 | 沪深300 `sh000300` |
| 科创50 | 头部「科创50ETF」 | 科创板总市值 | 科创50 `sh000688` |
| 创业板 | 头部「创业板ETF」 | 创业板总市值 | 创业板指 `sz399006` |

- 候选是简称里基准名紧挨 ETF 的场内基金。每个周按当周持有规模重选头部，留下达到最大那只 10% 以上的，最多 4 只。名单会变。
- 份额来自上交所、深交所。收盘价来自本机通达信；基金日线按三位小数还原后再乘份额。
- 全 A = 沪市主板 A + 科创板 + 深市主板 A + 创业板。不含 B 股和北交所。
- 周序列取当周最后一个交易日的份额和总市值。
- 同一页第二张图是基金份额合计，从通达信和交易所都有数的周开始。沪深300、创业板大约从 2013 年，科创50从产品上市起。先找份额高点，再找高点之后的低点，低点至今的净申购占当前份额的比例写在图上。这是申购赎回，不含价格涨跌。
- 持有规模图从交易所公布总市值的周开始，大约 2022 年。更早没有分母。
- 每组第三张是当周头部的周净申购。指数用本机通达信。沪深300合计至少 40 亿份且至少三只各超过 5 亿份，科创50合计至少 40 亿份且两只都超过 5 亿份，创业板合计至少 20 亿份且两只都超过 2 亿份。深红是指数下跌时达到这个规模，橙色是指数上涨时达到同样规模，绿色是合计净赎回达到同一门槛。这是多只一起买卖的特征，不是账户身份。
- 每张图下方都有色带，拖动选区或拖两端改显示区间。主图按选中的那段重新定纵轴。

## 多股 PE 分析页

一次分析多只股票时，仍用 `scripts/analyze_symbol.py`，估值口径和单图的画法与单股相同，只是把结果收进同一张普通横版网页，不再另写各只的单股页。只分析一只时才写 `cache/pe_<代码>_<行情日>/index.html`。这不是录屏 HTML。

```bash
cd tools/stock-screener
python scripts/analyze_symbol.py 00700 09988 01810
python scripts/analyze_symbol.py --title 513330_top10 --heading "恒生互联网ETF（513330）前十大重仓 PE" --lead "持仓来自华夏基金 2026-09-30 季报。" --weights 15.09,14.92,10.52,9.64,9.43,7.52,6.24,4.36,2.27,2.05 00700 09988 09999 03690 01810 09618 09888 01024 09660 00020
```

- 总览页写到 `cache/pe_<主题>_<行情日>/index.html`。`--title` 是目录名；不写时，少量股票用代码拼接，更多则用第一只加 `_etc只数`。`--heading` 是页面标题。
- 页顶是对照表，下面每只一块主图 + 下方色带，画法与单股页相同。
- 右侧固定「图表目录」：列出名称和代码，点击平滑滚动到对应图表；滚到哪只，哪一项高亮。窗口较窄时目录改到顶部横向排列，不要因此改成录屏页。
- `--weights` 可按名单顺序附上权重，对照表显示占净值，并只对当前有 PE 的股票做加权平均，须注明这不是基金或组合本身的估值。
- 当前 PE 为空，或有效 PE 点少于 5 个时，在该股图上写明，避免把空值和过短样本当成可靠分位。

## 全 A 历史 PE / PB 低分位筛选

入口：`python scripts/screen_low_valuation.py`。样本为通达信全 A（沪深京，默认排除指数和 ST）。PE / PB 口径与上文「单股 / 板块 PE / PB 口径」相同，分位也按该股官方序列计算（含当前未完成季）。默认入选：当前 PE、PB 分位均 ≤20%，且两条序列有效点均 ≥12；亏损或扣非为零的 PE 留空，不计入低分位。财务数据按报告期全量拉取东财主要指标（含扣非、每股净资产、总股本；有缓存不重拉），再在本地算分位。结果写 `cache/pe_pb_low_<行情日>/index.html`，并附 `all.csv` / `hits.csv`。表中「上市板」为沪深京板块，行业为通达信一级、二级、三级分类。不为每只股票生成分析图，也不是录屏 HTML。

## 港股 PE / PB

时点规则与 A 股相同：观察季 T 用本季末（或最新完整）收盘，盈利用上一季单季年化（×4）。差异如下。

| 项 | 规则 |
|----|------|
| 代码 | `00700`、`00700.HK` 或名称；内部为 `00700.HK` |
| 股价 | 通达信港股日线不复权港元收盘；未收盘前不用当天未完成的一根 |
| 盈利 | 上一季单季股东应占溢利（累计先拆单季）。没有 A 股扣非时不用扣非 |
| 汇率 | 锚定日及之前最近一个港币人民币中间价（HKDCNYC） |
| PE | （港元收盘 × 汇率）÷（上一季单季基本每股盈利 × 4） |
| PB | （港元收盘 × 汇率）÷ 每股净资产 |
| 股本 | 东财港股资产负债表股本可能为空，用股东应占溢利 / 基本每股盈利 |
| 当前点 | 上一自然季尚未披露时，未完成的观察季用已披露的最近一期配最新完整收盘 |
| 股息率 | 暂不计算，分析页显示为 — |
| 网页 | 仍由 `analyze_symbol.py` 写 `cache/pe_<5位代码>_<行情日>/index.html`，画法与 A 股相同，导语改为港股口径 |

页面上的绿线是港元股价。生成数据仅供参考，不构成投资建议。

```bash
cd tools/stock-screener
python scripts/analyze_symbol.py 00700
python scripts/analyze_symbol.py 00700.HK
python scripts/analyze_symbol.py 腾讯控股
```
