# 数据源规范（tools/stock-data）

| 数据 | 来源 | 模块 |
|------|------|------|
| 日线 OHLCV（前复权） | BaoStock | `src/market.py` |
| 季报营收/归母/扣非、股本、净资产 | 东财（经 AkShare） | `src/fundamentals.py` |
| 分红（已实施） | 东财分红配送 | `src/fundamentals.py` |
| 指标序列（市盈/市净/股息率等） | 由行情+财报计算 | `src/valuation.py` |

## 口径

- 复权：前复权（BaoStock `adjustflag=2`）
- 季报累计 → 拆单季后再滚 TTM
- 指标锚定价：季报 `NOTICE` **次月最后一个交易日收盘价**
- 动态市盈：锚定日价 / 每股 **TTM 扣非**
- 股息率：近 12 个月已实施现金分红 / 价格

出页流程见 `tools/stock-analysis`。
