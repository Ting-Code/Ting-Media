# 数据源规范（tools/stock-data）

公共**取数 + 财报缓存**（分析/估值在 `tools/stock-screener`）。

## 缓存边界（硬规则）

| 数据 | 是否缓存 | 说明 |
|------|----------|------|
| 通达信日线 / 周月线重采样 | **否** | 每次直读 `vipdoc`，现算复权与重采样 |
| 东财季报利润表 / 资产负债表 | **是** | 只缓存财报 → `tools/stock-data/cache/` |
| 分红 | 按实现 | 东财拉取；见 `fundamentals.py` |
| gbbq 解密 parquet | 可选加速 | 非 K 线缓存 |

缓存目录默认：`tools/stock-data/cache/`（可用 `STOCK_DATA_CACHE` 覆盖）。**不要**再写到仓库根 `cache/stock_data/`。

## 模块对照

| 数据 | 来源 | 模块 |
|------|------|------|
| 日线 OHLCV（默认前复权） | 通达信 `vipdoc` lday + `gbbq` | `src/market.py` |
| 周/月/季线 | 日线重采样 | `market.resample_ohlcv` |
| 季报利润表（全字段） | 东财（AkShare） | `src/fundamentals.py` → `cache/em_profit/` |
| 季报资产负债表（全字段） | 东财 | `src/fundamentals.py` → `cache/em_balance/` |
| 分红 | 东财 | `src/fundamentals.py` → `cache/em_dividend/` |

## 行情约定

- A 股复权：默认前复权（`adjust="qfq"`）；`bfq`/`none` 为不复权

## 调用示例

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path("tools/stock-data/src").resolve()))
from codes import resolve_code
from market import fetch_daily, resample_ohlcv
from fundamentals import fetch_quarterly_profit
code, name = resolve_code("<名称或代码>")
daily = fetch_daily(code)                 # 通达信直读，不缓存
weekly = resample_ohlcv(daily, "W")
profit = fetch_quarterly_profit(code)     # 财报，命中本地 cache
```

生成数据仅供参考，不构成决策依据。
