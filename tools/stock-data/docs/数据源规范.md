# 数据源规范（tools/stock-data）

| 数据 | 来源 | 模块 |
|------|------|------|
| 日线 OHLCV（前复权） | BaoStock（A 股）；其它市场另接 | `src/market.py` |
| 季报营收/归母/扣非、股本、净资产 | 东财（经 AkShare）等 | `src/fundamentals.py` |
| 分红（已实施） | 东财分红配送等 | `src/fundamentals.py` |
| 单股/板块估值序列 PE/PB | 按下方通用口径计算 | `src/valuation.py` |

## 单股 / 板块 PE / PB 口径（通用）

适用范围：**单股**与**板块/指数成分聚合**同一套时点规则（上一季财务 + 本季末价；未季末用最新价）。

对每个**观察季度 T**（自然季末；若当季未结束，则观察日=今日）：

| 项 | 规则 |
|----|------|
| 股价 | **本季末**最后交易日收盘；当季未结束 → **最新当日**收盘 |
| 盈利 | **上一季度**季报的**单季扣非净利润**（累计先拆单季） |
| 营收 | 上一季度单季营收（辅助序列，不进 PE） |
| 净资产 | 上一季度季报归母净资产（算 PB） |
| PE | 股价 ÷（上一季单季扣非 / 股本 × **4**）→ 年化；口播须说明 |
| PB | 股价 ÷（上一季归母净资产 / 股本） |

- 用「已披露的上一季扣非」配「本季末（或最新）价」。
- 单季扣非 ≤ 0 或缺失 → 该点 PE 留空。
- 旧口径「NOTICE 次月月末 + TTM 扣非」已废弃。


### 板块

- 时点与单股相同：观察季度 T 用**本季末价**（或最新价），盈利/净资产用**上一季度**已披露数据。
- 板块 PE/PB：先按口径算各成分（各用**自己的季末价**），再按选定权重聚合；权重与成分表须在 `meta`/口播中写明。**不是**「指数点位 ÷ 板块盈利」。
- 缺上一季扣非或净资产的成分：该点剔除并披露覆盖率，不拿其它季度偷偷填。
- 板块点位补齐规则见下方「PE 分析图」。

## PE 分析图（单股 / 板块出图时必须含）【已定稿】

同一张图、**同一套画法**（单股与板块通用）：

1. **三条序列**：季度末股价（或板块点位）、PE、PB（口径见上）
2. **纵轴**：**三条线各用独立纵轴**，各自按自身历史区间拉满画布（可加约 8% 边距）；**禁止**共用同一绝对刻度，也**不要**做「末点=100」归一（归一后走势接近的序列会视觉重叠）
3. **纵轴刻度数字**：可隐藏；数值以**鼠标悬浮**为准
4. **交互**：滚轮缩放时间轴、拖拽平移、框选缩放、`1Y/3Y/5Y/全部`、双击复位
5. **缺口**：某序列缺值勿连线填假（`connectgaps=False`）
6. **当前 PE**：可用虚线标出最新 PE（落在 PE 轴）

### 板块「点位」与 PE 的关系（勿混淆）

- **板块 PE/PB** = 各成分按上口径算出的 PE/PB，再按权重聚合。计算依赖的是**成分股价**，不是指数点位。
- **板块点位**（图画用）：
  - 有官方指数行情的区间 → 用官方指数季末收盘（未结束季用最新）
  - 官方指数尚未发布/无行情的更早区间 → 用**同期成分季末价的权重均值**，再按「与官方指数首个重叠季」对齐缩放，拼成连续点位序列（须在 `meta`/口播注明「早期为成分合成点位」）
- 因此：没有官方指数点位，仍可用成分价算 PE；点位序列应尽量补全，供与 PE/PB 同图对照。
