# 股票数据源规范（tools/stock-data）

本工具只负责 **取数与基础指标**，不负责录屏 HTML 母版。

## 数据源

| 数据 | 来源 | 模块 |
|------|------|------|
| A 股日线 OHLCV（前复权） | BaoStock | `src/market.py` |
| 季报营收/归母/扣非、股本、净资产 | 东财（经 AkShare） | `src/fundamentals.py` |
| 分红（已实施） | 东财分红配送 | `src/fundamentals.py` |
| 估值序列 PE/PB/股息率 | 由行情+财报计算 | `src/valuation.py` |

接口可能变更；重要结论请与交易所 / 巨潮交叉核对。

## 已锁定口径（取数/计算）

- 复权：前复权（BaoStock `adjustflag=2`）
- 季报累计 → 拆单季后再滚 TTM
- 估值锚定价：季报 `NOTICE` **次月最后一个交易日收盘价**
- 动态 PE：锚定日价 / 每股 **TTM 扣非**
- 股息率：近 12 个月已实施现金分红 / 价格

完整分析与出页流程见 `tools/stock-analysis/docs/方案.md`。

## 调用示例

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path("tools/stock-data/src").resolve()))

from codes import resolve_code
from market import fetch_daily
from fundamentals import build_fundamental_panel, fetch_dividends
from valuation import build_valuation_series, current_snapshot

code, name = resolve_code("宁德时代")
daily = fetch_daily(code)
fund = build_fundamental_panel(code)
div = fetch_dividends(code)
val = build_valuation_series(fund, daily, div)
snap = current_snapshot(fund, daily, div)
```
