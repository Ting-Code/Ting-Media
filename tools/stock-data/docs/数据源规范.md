# 数据源规范（tools/stock-data）

公共**取数 + 财报缓存**（分析/估值在 `tools/stock-screener`）。

## 缓存边界（硬规则）

| 数据 | 是否缓存 | 说明 |
|------|----------|------|
| 通达信日线 / 周月线重采样 | **否** | 每次直读 `vipdoc`，现算复权与重采样 |
| 东财季报利润表 / 资产负债表 | **是** | 只缓存财报 → `tools/stock-data/cache/` |
| 分红（已除息现金，含特别分红） | 否 | 通达信 `gbbq`，复用解密 parquet，不另缓存 |
| 分红（东财定期报告期） | 是 | 单只 `em_dividend/by_code`，全市场一期 `em_dividend/by_period` |
| gbbq 解密 parquet | 可选加速 | 非 K 线缓存 |

缓存目录默认：`tools/stock-data/cache/`（可用 `STOCK_DATA_CACHE` 覆盖）。**不要**再写到仓库根 `cache/stock_data/`。

## 模块对照

| 数据 | 来源 | 模块 |
|------|------|------|
| 日线 OHLCV（默认前复权） | 通达信 `vipdoc` lday + `gbbq` | `src/market.py` |
| 周/月/季线 | 日线重采样 | `market.resample_ohlcv` |
| 指数日线（不复权） | 通达信 `vipdoc`，带市场代码 | `market.fetch_index_daily` |
| 分板块日成交额 | 通达信日线按股票加总，不含指数和 ETF | `market.fetch_boards_daily_amount` |
| 季报利润表（全字段） | 东财（AkShare） | `src/fundamentals.py` → `cache/em_profit/` |
| 季报资产负债表（全字段） | 东财 | `src/fundamentals.py` → `cache/em_balance/` |
| 已除息现金分红（含特别分红，复权用） | 通达信 `gbbq` | `src/market.py` → `fetch_cash_dividends` / `fetch_a_share_cash_dividends` |
| 定期报告期现金分红（股息率分子，不含特别分红） | 东财分红送配 | `src/fundamentals.py` → `fetch_dividends` / `fetch_period_cash_dividends`，缓存 `em_dividend/` |

## 行情约定

- 估值和股息率的股价用成交价：`fetch_daily(code, adjust="bfq")`。
- `fetch_daily(code)` 默认前复权，只用于看复权走势。
- 股息率 = 最近四个已结束报告期的已实施每股现金合计 / 最新不复权收盘价。分子来自东财定期报告期（`fetch_dividends`），「现金分红-现金分红比例」是每 10 股税前派现。这张表不含特别分红。
- 通达信 `gbbq`（`fetch_cash_dividends`）含特别分红，用于复权。

## 调用示例

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path("tools/stock-data/src").resolve()))
from codes import resolve_code
from market import fetch_daily, resample_ohlcv
from fundamentals import fetch_dividends, fetch_quarterly_profit
code, name = resolve_code("<名称或代码>")
price = fetch_daily(code, adjust="bfq")   # 估值、股息率分母
chart = fetch_daily(code)                 # 前复权走势
div = fetch_dividends(code)               # 定期报告期每股现金，不含特别分红
weekly = resample_ohlcv(chart, "W")
profit = fetch_quarterly_profit(code)     # 财报，命中本地 cache
```

生成数据仅供参考，不构成决策依据。
