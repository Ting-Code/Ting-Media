# 赛道：财经（finance）

定位：科普 / 复盘向短视频与图文，**不荐股、不承诺收益**。

## 常用工具

- 单票复盘 HTML（9:16）：[`tools/finance/stock-analysis`](../../tools/finance/stock-analysis/)

## 本目录放什么

| 子目录 | 内容 |
|--------|------|
| `templates/` | 复盘口播、钩子、封面文案 |
| `prompts/` | 财经专用提示词 |
| `checklists/` | 录屏前 / 发布前检查 |
| `examples/` | 结构示例（不含侵权素材） |

模板与提示词按栏目逐步补齐。
