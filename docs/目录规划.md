# Ting-Media 目录规划

> 原则：赛道放「内容资产」，工具放「可运行能力」；跨赛道流程进 `shared/`。  
> 默认展示与录屏：**9:16 竖屏**。

## 结构总览

```text
Ting-Media/
├── AGENTS.md
├── README.md
├── docs/
│   └── 目录规划.md          # 本文件
├── shared/                  # 跨赛道通用
│   ├── workflow/            # 日更 SOP、9:16 录屏规范、发布复盘
│   ├── templates/           # 通用口播骨架、标题句式、检查表
│   └── prompts/             # 通用提示词
├── niches/                  # 按赛道沉淀内容资产
│   ├── finance/             # 财经
│   │   ├── README.md
│   │   ├── templates/
│   │   ├── prompts/
│   │   ├── checklists/
│   │   └── examples/
│   └── life/                # 生活
│       └── （同构）
├── tools/                   # 可运行工具（按用途）
│   ├── copywriting/         # 写文案类工具（规划）
│   ├── recording/           # 录屏 / 竖屏预览类工具（规划）
│   └── finance/
│       └── stock-analysis/  # A 股单票复盘 HTML
└── examples/                # 总库级示例（可选）
```

## 归类规则

| 类型 | 路径 |
|------|------|
| 某赛道口播稿 / 栏目 / 专用提示词 | `niches/<赛道>/` |
| 任何赛道都一样的流程与骨架 | `shared/` |
| 需要安装依赖、跑脚本的程序 | `tools/` |
| 财经复盘 HTML | `tools/finance/stock-analysis/` |

不要为每个赛道复制一整套 `tools` 代码；赛道只挂模板与提示词，工具尽量共用入口。

## 赛道 README 约定

每个 `niches/<赛道>/README.md` 写清：

1. 定位与栏目
2. 合规边界（财经须强调不荐股）
3. 常用工具路径（链到 `tools/...`）
4. 推荐 9:16 录屏分镜习惯

## 演进顺序

1. 先用 `niches/finance` + 现有 `tools/finance/stock-analysis`
2. 补 `shared/workflow`（9:16 录屏 SOP）
3. 再开 `tools/copywriting`、`tools/recording`
4. `niches/life` 有第一条栏目再填模板
