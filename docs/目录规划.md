# Ting-Media 目录规划

| 目录 | 放什么 |
|------|--------|
| `docs/` | 公共约定（本文件） |
| `episodes/<赛道>/YYYY-MM-DD_主题/` | 每期录屏内容（`index.html` 等；默认不入库） |
| `tools/<工具名>/` | 公共工具；**工具自己的规范放在该工具 `docs/`** |

```text
Ting-Media/
├── AGENTS.md
├── docs/
│   └── 目录规划.md
├── episodes/
│   └── <赛道>/YYYY-MM-DD_主题/
└── tools/
    ├── stock-data/          # 取数；规范 → docs/数据源规范.md
    └── stock-analysis/      # 录屏 HTML；规范 → docs/9-16-录屏规范.md 等
```

## 约定

- 赛道只用于 `episodes/` 归档，工具目录不按赛道拆。
- 母版出页、勿手写整页 HTML；细节见 `tools/stock-analysis/`。

## 使用原则

- 分析需求：先调用已有工具能力；**反复出现**再封装，避免冗余工具。
- 一期节目：工具出 HTML → `episodes/<赛道>/YYYY-MM-DD_主题/`。
