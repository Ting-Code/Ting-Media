# Ting-Media 目录规划

## 怎么理解这三块

| 目录 | 放什么 |
|------|--------|
| `docs/` | **公共规范**（所有赛道共用） |
| `episodes/` | **每期内容**：`<赛道>/YYYY-MM-DD_主题/` |
| `tools/` | **公共工具**（不按赛道分子目录；需要哪个就调哪个） |

AI 共用上下文：根目录 `AGENTS.md`。

## 结构

```text
Ting-Media/
├── AGENTS.md
├── README.md
├── docs/
│   ├── 目录规划.md
│   ├── 9-16-录屏规范.md
│   └── 录屏产物与生成方式.md
├── episodes/
│   └── <赛道>/                 # 仅内容分赛道，如 finance、life
│       └── YYYY-MM-DD_主题/
│           ├── index.html
│           ├── meta.json
│           └── cache/
└── tools/                      # 公共工具，扁平按工具名
    └── stock-analysis/         # A 股复盘 HTML 生成
```

## 约定

- **赛道只出现在 `episodes/`**（内容归档），不要在 `tools/` 下再套 `finance/`、`life/`。
- 公共规范 → `docs/`；某工具自己的说明 → `tools/<工具名>/` 内。
