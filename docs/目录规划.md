# Ting-Media 目录规划

## 怎么理解这三块

| 目录 | 放什么 |
|------|--------|
| `docs/` | **公共规范**（所有赛道共用）：9:16 录屏、产物命名、总说明 |
| `episodes/` | **每期内容**：按赛道 → `YYYY-MM-DD_主题/` 放录屏用 HTML 等 |
| `tools/` | **可运行工具代码**（不是第二套「规范仓库」）；工具自己的说明放在该工具目录内 |

AI 共用上下文以根目录 `AGENTS.md` 为准，不另建 Skill，也不用 `shared/` / `niches/` 再叠一层。

## 结构

```text
Ting-Media/
├── AGENTS.md                 # AI 总上下文（唯一入口）
├── README.md
├── docs/                     # 公共规范
│   ├── 目录规划.md
│   ├── 9-16-录屏规范.md
│   └── 录屏产物与生成方式.md
├── episodes/                 # 每期节目内容
│   └── <赛道>/               # 如 finance、life
│       └── YYYY-MM-DD_主题/
│           ├── index.html
│           ├── meta.json
│           └── cache/        # 可选
└── tools/                    # 工具代码
    └── finance/
        └── stock-analysis/   # 取数 + 套 PPT 母版；自带 AGENTS/docs
```

## 每期文件夹

`episodes/<赛道>/YYYY-MM-DD_主题/`

- 赛道：如 `finance`、`life`
- 主题：短、能认片即可（避免 `\ / : * ? " < > |`）
- 录屏打开：`index.html`

## 规范放哪

- 公共 → `docs/`
- 仅某工具相关 → 该工具自己的 `docs/` 或 `AGENTS.md`（例如估值口径在 `tools/finance/stock-analysis/docs/方案.md`）
