# Ting-Media 目录规划

| 目录 | 放什么 |
|------|--------|
| `docs/` | 公共规范 |
| `episodes/<赛道>/YYYY-MM-DD_主题/` | 每期录屏内容 |
| `tools/<工具名>/` | 公共工具（扁平；工具自带 docs） |

```text
Ting-Media/
├── AGENTS.md
├── docs/
├── episodes/
│   └── <赛道>/YYYY-MM-DD_主题/
└── tools/
    ├── stock-data/        # 金融取数（+ 数据源规范）
    └── stock-analysis/    # 录屏 HTML 生成（调用 stock-data）
```

- 赛道只用于 `episodes/` 归档内容  
- 工具不按赛道分子目录
