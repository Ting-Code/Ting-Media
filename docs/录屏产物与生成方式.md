# 录屏产物目录 & 生成方式

## 产物放哪

按 **赛道 → 每期节目文件夹** 归档：

```text
episodes/
  finance/
    2026-10-26_宁德时代复盘/
      index.html
      meta.json
      cache/
  life/
    2026-10-27_早起习惯/
      index.html
```

命名：`YYYY-MM-DD_主题`。

`episodes/` 默认 gitignore，只作本地录屏素材库。

## 一定要用 Python 写整页 HTML 吗？

**不必，也不该每次让 AI 从零写整页 HTML。**

更高效：

| 方式 | 适用 | 做法 |
|------|------|------|
| A. 数据管线套母版 | 财经复盘（真实行情） | `python tools/stock-analysis/scripts/generate_stock_html.py 宁德时代` |
| B. AI 写内容，母版不变 | 改口播/标题/要点 | 改本期 `index.html` 文案节点，或写内容包后再填充（母版 CSS/翻页不要动） |
| C. 禁止 | — | AI 每次新发明一版页面结构和安全区 |

原则：**版式+翻页+安全区 = 固定母版；字/数/图 = 可变内容。**  
Python 负责可靠取数并套母版；AI 负责选题与文案，而不是重写 PPT 壳。

推荐提示词：

```text
遵守 docs/9-16-录屏规范.md。
财经复盘请跑 stock-analysis 生成脚本，输出到 episodes/finance/日期_主题/。
不要从零手写整页 HTML；需要改文案时只改内容，保留翻页与安全区。
```
